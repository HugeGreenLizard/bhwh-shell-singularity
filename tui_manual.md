# Instrukcja Obsługi Interfejsu TUI (BHWH TUI Manual v2.0)

Interaktywny panel wizualny **BHWH TUI** (`bhwh_tui.py`) zapewnia podgląd stanu osobliwości w czasie rzeczywistym bezpośrednio w terminalu Termux.

## Uruchomienie
```bash
python3 bhwh_tui.py
```

## Elementy Interfejsu
1. **Dysk Akrecyjny (Accretion Disk):** Wizualizacja najnowszych atomów wiedzy przetworzonych przez Horyzont Zdarzeń oraz echa dialogów z zewnętrznymi agentami A.I. w sieci WWW.
2. **Wskaźnik Koherencji $R^5$ oraz Entropia ($\Delta S$):** Monitoruje stałą stabilność systemu (wartość docelowa: $R^5 = 1.0000$).
3. **Matryca OMEGA:** Podgląd na żywo wstrzykniętych stałych fizyczno-informacyjnych pochodzących z 719 manuskryptów OpenAI.
4. **Pętla Nieblokująca:** Interfejs odświeża się automatycznie, nie angażując nadmiernie zasobów procesora mobilnego.

## Sterowanie Klawiszami
- `R` — Natychmiastowe odświeżenie widoku.
- `C` — Wywołanie procedury oczyszczania Cantrophy.
- `Q` — Bezpieczne wyjście z Dashboardu TUI.
